# Recursive Pre-fix, Post-fix

To run this project, you will need the following tools:

1. python3.12.7
2. g++ 14.2.0
3. make 4.3

There are two ways to run the program:

1. Navigate to the /src directory, and call make run to run against the test.txt file.
2. Navigate to the /src directory, and call make build to build the executable, then call it with an input text file of your choice using the ./lab2 executable
3. Navigate to /test, and then call python3 prefix_postfix_test.py, and observe the output

This was made and tested with prefix_postfix_test.py, which creates and checks test cases
using an model I found online
